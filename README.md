# Checkpoint 04 — Front-end / TRIVOLUNE

Landing page em **HTML5 e CSS3** para a **TRIVOLUNE**, uma mochila urbana fictícia para estudo e viagem.

## Como visualizar

Abra `index.html` em um navegador atualizado, mantendo as pastas `css` e `assets` ao lado do arquivo. Não é necessário instalar pacotes ou iniciar um servidor.

## Estrutura do projeto

```text
.
├── index.html
├── css/
│   └── style.css
├── assets/
├── README.md
├── STYLE_GUIDE.md
└── .gitignore
```

## Responsividade

O layout usa Flexbox, Grid e media queries em **48rem (768px)** e **64rem (1024px)** para se adaptar a celular, tablet e desktop. As cores, a tipografia e os espaçamentos estão documentados em `STYLE_GUIDE.md`.
